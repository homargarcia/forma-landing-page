# MAKOA - muestra de desarrollo web

Segunda muestra para el portafolio de Homar G; Forma se conserva en la raíz del repositorio. No es el sitio oficial del negocio, ni un pedido pagado o un testimonio de cliente.

Marca real aportada por su propietario, manual de mayo de 2025 e identidad original de Luzino.dg. El logotipo se extrajo fielmente del manual, sin rediseñarlo. La carta fue transcrita y contrastada con sus páginas renderizadas; no se afirman precios o disponibilidad actuales.

Cinco secciones: presentación, métodos, carta con filtros y búsqueda, esencia y muestra PDF. Las interacciones son locales, sin cuentas, pagos, reservas, analítica, APIs ni envío de datos. HTML, CSS y JavaScript sin dependencias ni compilación. Abrir index.html manteniendo assets junto al código. El enlace a Forma apunta a ../.

Paleta del manual: #912A40, #EFE9DE, #D97C56 y #3D652E. La tipografía usa Lucida Fax si está instalada; Georgia es la alternativa del sistema. No se distribuyen archivos de Lucida Fax ni de otras fuentes propietarias. El logo conserva la tipografía modificada original.

Dos imágenes de ambiente generadas con el generador de imágenes integrado de Codex; se identifican como conceptuales. No son fotografías del local, sus personas o productos reales. No se reproduce el manual completo, códigos QR, redes sociales ni contactos.

Diseño, código, maquetación del menú y revisión asistidos por IA. No se atribuye a Homar G la creación de la identidad de MAKOA. Revisar texto, precios y derechos de imágenes antes de convertir una muestra en sitio comercial oficial.
